# fastasfsave — downloads

**⌘-click any image. It's saved. Full size.**
A tiny free Mac app (+ Chrome extension) that saves the full-size original of any picture you ⌘-click.

👉 **Website & instructions: https://fastasfsave.com**
👉 **Latest download:** [fastasfsave.dmg](https://github.com/garbagetrash9999/fastasfsave-releases/releases/latest/download/fastasfsave.dmg)

This repository only hosts the installers and the update feed (`appcast.xml`) that the app checks for new versions.
Requires macOS 14 or newer (Apple Silicon or Intel).
